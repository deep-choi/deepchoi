
# 📝 변경 내역 (CHANGELOG)

## v2.1.0 (Latest)
**"인라인 편집 & 시크릿 도어 업데이트"**

### ✨ 새로운 기능 (New Features)
1. **인라인 수정 (Inline Editing) 구현**
   - 게시글 상세 화면에서 '수정' 버튼을 눌러 내용, 제목, 테크 스택을 즉시 수정할 수 있습니다.
   - 직관적인 WYSIWYG 경험을 위해 텍스트가 입력 필드로 자연스럽게 변환됩니다.

2. **비밀의 문 (Secret Auth) 시스템**
   - 네비게이션 바에서 '관리자' 메뉴를 제거했습니다. (Hidden UI)
   - `/admin` 주소 직접 입력을 통해서만 접근 가능하며, 비로그인 시 접근이 차단됩니다.
   - 관리자용 프리미엄 로그인 UI 및 로그아웃 기능을 추가했습니다.

### 🎨 디자인 & UX 개선
- **플로팅 액션 버튼**: 상세 페이지 우측 하단에 수정 모드 진입/저장/취소를 위한 직관적인 버튼을 배치했습니다.
- **애니메이션 강화**: 로그인 화면, 버튼 상호작용 등에 부드러운 전환 효과를 적용했습니다.
- **일반 회원가입 및 로그인**: 누구나 이메일로 가입(`Signup`)하고 로그인(`Login`)할 수 있는 시스템을 구축했습니다.
- **댓글 시스템 (Comments)**: 상세 페이지 하단에 댓글 기능이 추가되었습니다. 로그인한 사용자라면 누구나 의견을 남길 수 있습니다.
- **권한 관리**: 일반 회원은 '댓글 작성'만 가능하며, 관리자(Admin)는 '글 수정/삭제' 및 '댓글 관리' 권한을 가집니다.
- **새 글 작성 버튼 복구**: 관리자 대시보드 제거 후 사라졌던 '글쓰기' 기능을 복구했습니다. 홈페이지 우측 하단에 관리자 전용 **파란색 플러스(+) 버튼**을 추가했습니다.
- **데이터 초기화 (Data Reset)**: 포스트가 열리지 않던 문제를 해결하기 위해 데이터 저장소를 초기화했습니다. (v3로 마이그레이션)
- **관리자 대시보드 제거**: 복잡한 관리 목록 페이지를 완전히 삭제했습니다. 로그인 후 바로 홈페이지로 이동하며, 관리 작업은 각 게시글 상세 페이지에서 직관적으로 수행합니다.

## v2.0.0
**"Headless CMS 아키텍처 개편"**

### ✨ 주요 변경 사항
1. **CMS 기반 데이터 구조 도입**
   - `Author` (작성자), `Subtitle` (부제목), `Tags` (태그) 필드를 추가하여 블로그 기능을 고도화했습니다.
   - `projectService`를 통해 데이터 CRUD(생성, 읽기, 수정, 삭제)를 체계적으로 관리합니다.

2. **UI/UX 리뉴얼**
   - **Selected Works**: Apple 스타일의 탭 메뉴와 호버 인터랙션이 적용된 메인 그리드를 구현했습니다.
   - **프리미엄 상세 페이지**: 와이드 히어로 이미지와 여백을 활용한 매거진 스타일 레이아웃을 적용했습니다.

3. **관리자 대시보드 구축**
   - `/admin` 페이지에서 전체 포스트 목록을 조회하고 새 글을 작성할 수 있는 기초 환경을 마련했습니다.
