
# 📂 NEXBOT UI/UX Portfolio V2
> 현대적이고 미니멀한 "Headless CMS 스타일" 포트폴리오 웹사이트입니다.

## 🌟 프로젝트 개요
이 웹사이트는 단순한 정적 포트폴리오를 넘어, **관리자가 직접 콘텐츠를 관리(CMS)** 할 수 있는 기능을 포함하고 있습니다.
방문자에게는 완성도 높은 작품을 보여주고, 관리자는 비공개 경로를 통해 접속하여 글을 작성하거나 수정할 수 있습니다.

## 🏗️ 폴더 구조 설명 (누구나 알기 쉽게)
```
📦 nexbot-ui_ux-portfolio (1)
 ┣ 📂 public          # 이미지, 아이콘 등 정적 파일들이 모여있는 곳
 ┣ 📂 src             # 실제 소스 코드가 들어있는 핵심 폴더
 ┃ ┣ 📂 assets        # 로고나 작은 이미지들
 ┃ ┣ 📂 components    # 레고 블록처럼 재사용 가능한 부품들 (예: 버튼, 카드, 네비게이션 바)
 ┃ ┣ 📂 data          # 초기 게시글 데이터가 저장된 곳 (데이터베이스 역할)
 ┃ ┣ 📂 pages         # 실제 화면 단위의 페이지들
 ┃ ┃ ┣ 📜 Home.tsx       # 메인 홈페이지
 ┃ ┃ ┣ 📜 PostDetail.tsx # 게시글 상세 페이지 (인라인 수정 기능 포함)
 ┃ ┃ ┗ 📜 Login.tsx      # 관리자 로그인 페이지 ('비밀의 문')
 ┃ ┣ 📂 services      # 데이터 저장, 로그인 등 보이지 않는 기능을 처리하는 곳
 ┃ ┣ 📜 App.tsx       # 웹사이트의 지도 같은 역할 (어떤 주소로 가면 어떤 페이지를 보여줄지 결정)
 ┃ ┗ 📜 types.ts      # 데이터의 모양(규격)을 정의한 설계도
 ┗ 📜 package.json    # 프로젝트 정보와 설치된 도구 목록
```

## 🔑 주요 기능 설명
1. **비밀의 문 (Hidden Admin)**
   - 일반 방문자에게는 '로그인' 버튼이 보이지 않습니다.
   - 주소창에 `/admin`을 입력해야만 관리자 페이지로 갈 수 있습니다.
   
2. **인라인 수정 (Inline Editing)**
   - 관리자로 로그인하면, 게시글 상세 페이지에 '수정' 버튼이 생깁니다.
   - 버튼을 누르면 제목, 내용을 그 자리에서 바로 고칠 수 있습니다.

3. **프리미엄 디자인**
   - Apple 웹사이트 같은 부드러운 애니메이션과 깔끔한 여백을 적용했습니다.

## 🚀 실행 방법
1. 터미널을 엽니다.
2. `npm run dev` 명령어를 입력합니다.
3. 브라우저에서 `http://localhost:3000`으로 접속합니다.
